## Consensus / arbitration notes

1. **Uniformity theorem**: false as stated. Counterexample in the paper's own DSL: m=2, ℓ=2, allowed={0,2} (2∣4) yields 25%/75%. Correct sufficiency condition: the admissible set is a complete residue system mod m — holds for every shipped layout (contiguous {1..m}), so all concrete results survive. Restate the theorem; prove or properly bound the m/2^ℓ TV claim for general allowed sets; fix ⌊256/5⌋=50/⌈256/5⌉=51 → 51/52; fix "m=4 at ℓ=12" → ℓ=8.
2. **Birthday bound**: `structured-evidence.json` records `birthdayBound50: 2.71e+18` (the 122-bit v4 bound) for a 50-random-bit layout — wrong. Conservative 50-bit bound: 3.95×10^7 (correctly computed in `benchmark_results.json`); the accurate within-tick model (50 random + 16 counter bits, wall-clock-concentrated timestamp) gives ≈10^10. Fix the artifact and state the model in §4.4.
3. **DB locality**: the 10.4× partition-scan ratio uses the unindexed baseline the paper's own §3.2 argues against. Equal-capability comparison: indexed probe 3.09 ms [2.68, 3.49] vs GenoID PK scan 8.40 ms [3.10, 13.69] — mean 2.7× slower, CIs nearly touch (Welch t≈2.8, df≈4, p≈0.05: borderline, not established). Per-rep values not archived (cold-first-rep hypothesis unverifiable). PostgreSQL reversal: shard-first 41% slower than uuid_v7 on inserts (untracked `db-native.json`). Honest claim: zero-index partition extraction + insert-tax avoidance + storage savings, at the cost of slower partition reads than an indexed baseline, engine-dependent.
4. **123/123 NIST**: expected under the null (P=0.99^123≈29%). Per-test α=0.01 without family-wise correction is defensible under NIST STS convention — say so explicitly (the repo applies Holm–Bonferroni to its own 9-test battery, an inconsistency). Archive the failed draw (p=0.0057) and disclose the draw count (optional-stopping risk).
5. **O(64^k) framing**: the comparison is against whole-candidate rejection; per-field rejection is O(k) in expectation. The defensible advantage is worst-case boundedness (no geometric tail), not exponential separation. State the per-field alternative.
6. **pg_uuid_v8**: internally contradicted (AES in §1/§5.1 vs XOR in §7.3; the benchmarked baseline is a local XOR, v4-compatible reimplementation — disclose it). Entropy row: 74 actual random bits, not "up to 122".
7. **Pool size**: 256 (§2.2) vs 1024 (§4.2/§5.6) contradiction; compiled production path pools 256, pooled fallback holds 1024. Forward-secrecy window (≤1024) is path-dependent — scope it.
